# Image Recognition Demo

ブラウザ上で動作する簡単な画像認識デモです。

## 機能

- 画像ファイルの選択
- 選択した画像のプレビュー
- ファイル名・サイズ・MIME typeの表示

## 起動方法

`index.html` をブラウザで開くだけで動作します。
